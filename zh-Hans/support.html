支持

修改规则前，先核对实际设备、权限和路由状态。

  1. 分别检查指定目标与实际设备。保存规则不等于路由成功。
  2. 使用 App 输入时，在该 App 的音频设置中选择对应的 AudioLock 输入。设备名称不构成访问控制。
  3. 目标不可用时，重新连接或明确选择另一个目标。不要因此推断其他 App 已停止录音。
  4. 求助时提供 App/构建、macOS 版本、设备名称、方向和操作步骤。不要附上录音、账户资料或购买凭据。

打开支持入口

GitHub Issues 和附件是公开的。请勿发布录音、Apple 账户或支付资料、凭据及其他私人信息。
