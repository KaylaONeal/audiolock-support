How it is intended to work

Choose a default microphone and output device from the menu bar. Turn each lock on separately. If macOS changes a locked default, AudioLock restores your selection while the device is available. Pause a lock whenever you want to switch freely.

For supported apps, set separate input and output routes so different apps can record and play through different devices at the same time. Input routing requires selecting the corresponding AudioLock input in the target app. A saved rule is shown as active only after its route starts successfully.

Know what is happening • See the selected target and the device actually in use. • Keep device choices when hardware disconnects. • Wait for a disconnected app output rather than automatically playing through another device. • Pause routing and manage app rules from the menu bar.

Global locks change macOS defaults. Apps that explicitly select their own devices may ignore these defaults. Independent input routing is limited to apps that can select the supplied input device. Protected or otherwise uncapturable content may not support output routing. Device support and added latency depend on the tested setup. AudioLock does not control the internal microphone setting of every third-party app.

Common questions

Will every app follow a locked default?

No. Apps that explicitly choose a device can ignore the system default. Independent input requires selecting the supplied AudioLock input in a supported app.

Can two apps use different inputs and outputs at once?

That is the full-version goal. It remains unverified until two real apps pass simultaneous four-path testing; a saved rule is not proof of delivery.

Will disconnected headphones send sound to the speakers?

The output design keeps capture active and discards audio while waiting for the target. Real disconnect and crash behavior still requires verification; there is no blanket no-speaker guarantee.

Will the trial charge me automatically?

The required trial is separate and has no automatic paid conversion. Target prices are US$0.99 for one year or US$4.99 lifetime. Products and trial policy are still being validated.
