# AudioLock product and support pages

Public product, support and privacy information for AudioLock. This repository contains only the static information site. The app is under development; full audio routing and App Store release remain unverified. No app download is offered.

HTML pages use noindex while development continues. This is a search directive, not access control or a guarantee that every public URL is excluded from search.

Support: use this repository’s Issues. Issues and attachments are public. Do not post audio recordings, Apple Account details, payment information, credentials or other private data.
